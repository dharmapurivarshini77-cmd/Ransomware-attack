# Ransomware-attack
Detection of Ransomware Attacks Using Processor and Disk Usage Data is a cybersecurity project that uses Machine Learning and Deep Learning models such as Random Forest, XGBoost, DNN, and LSTM to detect ransomware from CPU and disk activity, providing fast and accurate threat detection.
# 🛡️ Detection of Ransomware Attacks Using Processor and Disk Usage Data

## 📌 About the Project

This project detects ransomware attacks using processor and disk I/O activity data. It applies Machine Learning and Deep Learning algorithms, including SVM, KNN, Decision Tree, Random Forest, XGBoost, DNN, and LSTM, to identify potentially malicious behavior.

The system focuses on fast ransomware detection while maintaining low system resource usage. The project also compares multiple Machine Learning and Deep Learning models based on their detection performance.
